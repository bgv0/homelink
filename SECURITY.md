# Security

Please report security problems privately, not in public issues: use
**GitHub → Security → Report a vulnerability** on this repository.

Helpful to include: what you found, how to reproduce it, and which version
(`homelink --version`, or the version in the installer name).

Things in scope include: anything that lets an unpaired device use a host,
reach a host's local network when that's switched off, read or change
traffic, or that lets the full-tunnel helper (which runs with admin rights)
be misused.
